    How to use this

    Every entry is a tool, library or guide I saved and then checked. Each one has a plain summary, what it does, how to try it, and a safety rating checked against its real source.

    Browse by what you want to do, or search below. Open an entry to see the details. The words in the next section come up a lot.

    Eight words you will see

    Claude Code
    Anthropic's AI assistant that works inside your terminal and your project folders. Many tools here plug into it.
    Skill
    A folder of instructions that teaches Claude one job. You add it once, then call it by name, like /grill-me.
    Plugin
    A bundle of skills, commands and settings you install in one go.
    MCP server
    A connector that lets an AI assistant use another app, like your design tool or a web search.
    Repo
    A project's code on GitHub. Stars count how many people bookmarked it. That shows popularity, not safety.
    npx
    A terminal command that downloads and runs a package in one step. Read what a command does before you run it.
    Jev
    A model from TypeSafe AI that makes fast, structured decisions for software. It returns a typed answer with a confidence score instead of written text. It is paid and in early access, and a few tools here use it. TypeSafe AI's announcement.
    License
    The rules for using the code. MIT and Apache-2.0 let you use it freely, including at work.

    Safety ratings

    OKChecked the real source: a known owner, an open license, nothing unexpected on install.
    CautionLegitimate, with something to watch: a young project, one maintainer, it installs hooks, or it holds logins to your other apps.
    UnverifiedI couldn't confirm who is behind it. Look closely before you sign up or install.
